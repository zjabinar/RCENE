> Weave your own banig: see how a Basey mat is made, then plait a pattern strand by strand and take it home as an image. Heritage you can hold, made with code. This is the most literal answer to *The Living Tapestry: Weaving the Threads of Innovation and Heritage*.

## Problem

Banig weaving in Basey, Samar (mats plaited by hand from dyed tikog grass) is one of the region's living craft traditions, but a visitor rarely sees how a pattern is actually built. PROPOSALS #17 calls this the strongest theme match with the weakest civic-impact story, and warns that photos and stories must be gathered beforehand. So this MVP uses **no photos**: its imagery is drawn by the same pattern code the visitor plays with, and every story is marked as a draft to verify with weavers. Be honest in the pitch: this is cultural appreciation and a souvenir for P8, not a public service. Scope is deliberately tight: no data, no map, no accounts.

## Domain functions (test-first in `src/domain/`)

```ts
type Motif = "checker" | "twill" | "diamond";
type PaletteId = "natural" | "sunset" | "sea" | "fiesta";
interface PatternSpec { motif: Motif; size: number; block: number; palette: PaletteId; colors: 2 | 3 | 4; diagonal: boolean }
interface Grid { w: number; h: number; cells: Uint8Array } // palette index per cell, row-major
```

- `generate(spec: PatternSpec): Grid` with `at(x, y)` = palette index. Formulas (`mod` is always non-negative):
  - checker: `(floor(x / block) + floor(y / block)) mod colors`
  - twill: `floor(mod(x − y, block · colors) / block)` (diagonal stripes)
  - diamond: with `P = 2 · block · colors`, `dx = |mod(x, P) − P/2|`, `dy = |mod(y, P) − P/2|`: `floor((dx + dy) / block) mod colors` (nested diamonds)

  Cases: deterministic (same spec → identical `cells`); `w === h === size`; every value `< colors`; checker: `at(0,0) !== at(block,0)` and `at(0,0) === at(block,block)` when `colors === 2`; twill: `at(x,y) === at(x+1,y+1)`; diamond: `at(x,y) === at(y,x)` and `at(x,y) === at(P−x,y)` for `0 < x < P`.
- `strandAt(x: number, y: number): "warp" | "weft"` — `(x + y)` even → warp (plain over-one-under-one plait). Cases: alternates along a row and along a column.
- `cellRect(x, y, cellPx, strand, gapPx): { x: number; y: number; w: number; h: number }` — warp strands are narrowed horizontally, weft strands vertically. Cases: warp rect width = `cellPx − 2·gapPx`, full height; weft the reverse; origin offsets correct.
- `parseSpec(input: unknown): PatternSpec` (zod with defaults and clamping) — cases: size 5 → 12, size 100 → 64; unknown motif → default; missing fields → defaults; `colors` limited to 2–4.
- `encodeSpec(spec): string` and `decodeSpec(code: string | null): PatternSpec | null` — compact form such as `diamond.32.3.sea.3.1`. Cases: round trip for every motif × palette; garbage, wrong field count or out-of-range values → `null`; `null` input → `null`.
- `PALETTES: Record<PaletteId, { nameKey: string; hex: [string, string, string, string] }>` and `contrastRatio(hexA, hexB): number` (WCAG formula). Cases: each palette has 4 distinct valid hex colours; colour 0 vs colour 1 has a contrast ratio ≥ 1.5, so the motif still reads in greyscale and for colour-blind viewers.
- `surpriseSpec(rng: Rng): PatternSpec` — cases: deterministic for a seed; always passes `parseSpec` unchanged.

Drawing (`src/canvas/drawWeave.ts`, not a domain test target): `drawWeave(ctx, grid, palette, { cellPx, diagonal, rows? })`, where `rows` (0…h) limits how many weft rows are drawn, for the weave-in animation. Preview, thumbnails, story swatches and export all call it.

## Data

- No data layers; `useLayer` is not used. Nothing from `D:\monica` or any LGU source.
- Synthetic data: none. Pattern presets and palettes are authored in `src/content/presets.ts`; "Surprise me" uses `createRng(1701)`.
- Store `createSyncedStore("17-banig:maker")`, version 1: `{ spec: PatternSpec; saved: PatternSpec[] /* max 6 */; surpriseCount: number }`.
- No personal data. The palette names are neutral (Natural, Sunset, Sea, Fiesta) and make no claim about traditional dyes.

## Experience

- **Tone:** warm and crafted. The woven grid is the visual language of the whole app: section dividers are thin woven bands drawn by `generate` + `drawWeave`.
- **Wow moment:** "it weaves itself". On every spec change the canvas re-plaits row by row: weft rows slide in from alternating sides over about 0.6 s. GSAP tweens a plain progress object and calls `drawWeave(…, { rows })` in `onUpdate` (never React state per frame). Recipe: `gsap-motion` → core `useGSAP` pattern with `dependencies: [specCode]` and `revertOnUpdate`.
- On `/`: SplitText headline reveal plus a woven band drawing in; story cards weave in from alternating sides as they enter the viewport (ScrollTrigger batch). Optional `SmoothScroll` from `@rcene/ui/motion` on `/` only.
- **Accessibility:** canvas `role="img"` with a spec-based `aria-label`; all controls labelled and keyboard-operable; palette swatches carry their names (colour is never the only cue); export, copy and save confirmations in an `aria-live` region; reduced motion → patterns draw instantly, no slides, no SplitText; WCAG AA for all text at 390 and 1280 px.

## Golden-path demo (≤ 2 minutes)

1. `/` on the laptop: the hero weaves in; scroll the story cards ("Draft — to verify with Basey weavers"). Say it plainly: strongest theme match, lowest civic impact, so it was kept small.
2. On the "Patterns" card press "Weave this" → `/weave` opens with a diamond preset and plaits itself.
3. Switch the palette to Fiesta and block size to 2 → it re-weaves; turn on "Diagonal plait".
4. "Download PNG" → open the file to show it matches.
5. "Copy link" → paste into a phone-width window → the identical pattern; switch that window to Waray.
6. If R17.5 shipped: "View in 3D" → press "Angle" to show the over/under depth of the pattern just designed.
